# Contributing

Thanks for considering a contribution!

1. Open an issue describing the bug or proposed feature.
2. Make a focused branch with tests for behavior changes.
3. Run `npm test` and `npm run check`.
4. Open a pull request with screenshots for UI changes.

Do not commit API keys, Codex credentials, local transcripts, personal
workspace paths, access tokens, or any files from `.local/`.
Security-sensitive changes require extra review.
